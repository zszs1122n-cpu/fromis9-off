# 프나 오프 일지

공개 사이트는 `docs/index.html`과 `docs/events.json`을 사용합니다.

일정은 매일 오전 9시(Asia/Seoul)에 GitHub Actions로 갱신합니다. 영상 캘린더의 기존 오프 기록에, 필굿의 정확한 제목 **앞으로 일정 스케줄** 최신 게시물에서 확인한 예정 오프를 합칩니다. Drive 일정표 이미지를 읽는 과정은 필요하지 않습니다.

갤러리는 **개념글 → 전체글 → 검색엔진** 순서로 탐색합니다. 일치하는 글이 발견되면 게시 시각과 번호를 비교하고 원문 전체를 읽습니다. 전날 22시부터 당일 02시까지 올라온 글도 해당 아침의 원문에 포함합니다. 본문 끝이나 날짜/요일을 확인할 수 없거나 일정이 이미지로만 제공되면 검증 실패로 처리합니다.

유튜브·라디오·TV·영통과 미확정 일정은 예정 오프에 넣지 않습니다. 원문에 없는 공연 시간이나 사운드체크도 만들지 않습니다. 캘린더와 겹치는 일정은 기존 ID에 원문 링크와 확인된 시간을 보완해 참석 기록을 유지합니다. 새 갤러리 일정은 게시물 번호가 바뀌어도 같은 ID를 사용합니다.

원문 접근/검증 실패 시 마지막 확인 일정을 보존하고 사이트에 실패 상태와 원문 날짜를 표시합니다. 정상적으로 새 원문을 확인하면 그 글에서 빠진 미래 갤러리 일정은 제거하며, 지난 일정 기록은 보존합니다. 캘린더 장애 시에도 갤러리를 확인하고 마지막 캘린더 기록을 유지합니다.

로컬 실행:

```powershell
python -m pip install -r requirements.txt
python -m unittest -v test_gallery
$env:OFF_OUT = 'docs/events.json'
python sync.py
```

`OFF_OUT`을 지정하지 않으면 `out/events.json`에 저장합니다. `index.html`은 별도의 로컬 화면이며 공개 사이트와 구조가 다릅니다.
